### A browser version of the classic strategy game *Battleship*. Built  with vanilla JavaScript, this project focuses on modular architecture, intuitive UI, and intelligent computer AI.

## Demo
<video src="images/battleshipDemo.mov" controls></video>


## Features
### Gameplay
- Custom ship placement
- Intelligent, human-like AI
- Fast-paced, turn-based gameplay

### Technical 
- Modular (ESM) architecture
- Test-driven development using Jest
- Validation checks

## What I Learned
Battleship forced me to think much more about architecure and design than other projects

Some of the biggest challenges were:
- Creating a "smart" AI
- Separating UI and logic (many improvements could be made here)
- Writing code that could be tested

## Future Improvements
- Multiplayer "pass device" option
- Slower, more interactive AI
- Difficulty settings
- Refactoring: looser coupling and greater reusability
